# 第一版开发范围

## 已确认需求

- 面向本科数学类课程（离散数学、概率论等），多课程独立资料库。
- 本机运行，手机与电脑通过同一 Wi-Fi 使用；访问口令保护。
- 文字型 PDF、文字和公式题；不包含 OCR、图像题识别。
- 自定义／随机题型，范围、题量、难度、分值可控。
- DeepSeek 根据教材片段生成题目、答案、解析、评分要点及依据页码。
- 试卷预览、编辑、删除、单题重生成；学生试卷和答案分开打印。
- 在线查看／简短文字答题，纸上完成复杂计算和证明，自行评分。
- 历史试卷、错题、收藏；本地 SQLite 保存。

## 实施顺序

1. 工程、数据模型、口令登录、PDF 解析和修正。
2. 检索、后台逐题生成、校验、失败重试、试卷管理。
3. React 响应式界面、公式排版、打印、自评分和错题。
4. API 测试、浏览器验证、启动脚本和使用文档。

## 边界

页码以 PDF 实际页序（从 1 开始）为准，不等同于书中印刷页码。目录仅在 PDF 包含可用书签时提取。检索是本地关键词和范围检索，不是向量语义检索。生成质量仍需人审，无法保证证明和公式绝对正确。真实 DeepSeek 调用需用户自行配置密钥。代码仓库不包含教材、密钥、学习记录。
